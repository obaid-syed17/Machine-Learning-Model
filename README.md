# Titanic Survival Prediction using Machine Learning

## 📌 Project Overview

This project is a **Machine Learning model** that predicts whether a passenger aboard the **Titanic** would have **survived or not survived** based on passenger data. The model is built using **Logistic Regression** and evaluates its performance using multiple classification metrics.

## 🚀 Features

* Data preprocessing using **Pandas** and **NumPy**
* Binary classification using **Logistic Regression**
* Predicts the probability of passenger survival
* Calculates model **accuracy**
* Generates a **Confusion Matrix**
* Produces a **Classification Report** including:

  * Precision
  * Recall
  * F1-Score

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn (sklearn)
* Logistic Regression

## 📂 Project Workflow

1. Load the Titanic dataset.
2. Clean and preprocess the data.
3. Split the dataset into training and testing sets.
4. Train the Logistic Regression model.
5. Predict survival on the test data.
6. Evaluate the model using:

   * Accuracy Score
   * Confusion Matrix
   * Classification Report

## 📊 Model Evaluation

The model's performance is evaluated using:

* **Accuracy Score** – Measures the overall prediction accuracy.
* **Confusion Matrix** – Shows the number of correct and incorrect predictions.
* **Classification Report** – Provides precision, recall, F1-score, and support for each class.

Run the Python script:

```bash

```

* Train the Logistic Regression model.
* Predict passenger survival.
* Display the model accuracy.
* Print the confusion matrix.
* Show the classification report.
